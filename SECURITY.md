## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it responsibly. **Do not disclose security vulnerabilities publicly** until they have been addressed and a patch has been released.

You can report vulnerabilities through one of the following methods:

* **Private Vulnerability Reporting:** Go to the [Security tab of the AURA repository](https://github.com/DitoNugroho/AURA/security) and click **Report a vulnerability** to open a private advisory draft.
* **Direct Contact:** Alternatively, you can reach out directly via email to the repository owner.

Please include as much detail as possible in your report to help reproduce and fix the issue quickly:
* Type of vulnerability (e.g., injection flaw, exposed secret, dependency issue)
* Full paths of source file(s) related to the vulnerability
* Step-by-step instructions to reproduce the issue
* Proof of concept or exploit code (if applicable)

Thank you for helping keep this project secure!
